**已完成**：
- 项目骨架 `src/rmt_portfolio/{data,rmt,portfolio,backtest,utils}`
- `config.py`：YAML 驱动的 Config（支持属性访问 + 深合并 + 路径解析），Universe dataclass
- `rmt/mp_law.py`：MP 律完整实现
  - `mp_edge(σ,q)`：λ± = σ²(1±√q)²
  - `mp_density`：q≤1 积分为 1；q>1 积分 1/q，原子 1-1/q 在 0
  - `_mp_cdf`：**用数值积分密度实现**（比解析式稳健，避免符号/分支错误）；另有 `_mp_cdf_analytic` 供交叉验证
  - `_mp_median_unit(q)`：σ=1 时 MP 律中位数（二分法）
  - `fit_mp_sigma(ev, q, method)`：4 种 σ 估计 —— `median_bulk`(默认)/`mean_bulk`/`max_eigen`/`cdf_fit`
  - `_cap_sigma`：防止拟合 σ 导致无 eigenvalue 被判为噪声
  - `MPLaw` dataclass：打包 q/σ/λ±/诊断
- `rmt/denoise.py`：8 个估计器
  - `sample_cov`, `ledoit_wolf_linear`(sklearn), `ledoit_wolf_constant_correlation`(自研向量化 2003 式)
  - `rmt_hard_threshold`（阈值下塌缩到噪声均值，**保 trace**）
  - `rmt_soft_threshold`（幂次平滑 taper）
  - `rmt_rie`（QuEST/Stieltjes 变换非线性收缩，**保证每个方向只收缩不放大**）
  - `factor_model_cov`（前 k 个 PC + 对角残差）
  - `denoise()` 高层 API 返回 `DenoiseResult`（含前后谱、MP law、诊断）

**关键调试记录（踩坑）**：
1. MP CDF 解析式一开始写错：F(λ₊) 返回 0.5 而非 1.0。**改用数值积分密度实现**，已验证 F(a)=0、F(b)=1、F(median)=0.5、密度积分=1。
2. `fit_mp_sigma` 的 `median_bulk` 最初用「下四分位/中位数」量纲不匹配 → σ 错成 0.16。**修正为 σ=√(median(bulk)/m(q))**。
3. RIE 的 trace 重缩放会重新放大 λ_max，违反收缩性质。**改为迭代「缩放→按 raw 值封顶」**，并报告 trace 残差。
4. `noise_variance_share` 原用 mean×count 计算，PSD 投影后失真。**改为直接用噪声特征值之和/trace**。

**验证结果（重要，可写进论文）**：
- 纯噪声 σ=1.0：拟合 σ=0.85~0.96 ✓，误判「信号」2~8/40~100（符合有限样本假阳性期望）
- 5 真实因子 + 噪声 σ=0.5：拟合 σ=0.468~0.487 ✓，检出 6~7 个信号特征值（真实 5 个）✓
- 三种 σ 方法（median/mean/cdf）互相印证一致（σ≈0.48）✓

**核心结果（已定稿，用于论文/README/简历）**

谱结构（us_sector_etf, N=16, T=252, q=0.063, σ̂=0.431）：
- **7/16 特征值突破 λ₊，承载 91.9% 方差**；λ₁=8.60 达 λ₊ 的 **29.5 倍**
- 特征向量滚动重叠度：rank1 **0.9987**，rank2 0.9926，rank3 0.9602，rank≥8 跌到 0.89
- 中国面板：8 个信号，λ₁ 占 60.3%（比美股更集中，符合 A 股「齐涨齐跌」）

**核心结果（本文主张：换指标才有信号）**
- 已实现夏普：三个市场三个不同赢家（CN=factor_model 0.179 / US=ledoit_wolf 0.447 / highq=sample 1.026），跨度全在 0.06 内 → **无法区分估计量**
- **QLIKE 风险预测损失：RIE 在三个市场一致第一**
  - US: 0.43789 vs sample 0.51309 → **−14.7%**
  - CN: 0.51087 vs 0.60385 → **−15.4%**
  - highq (N=50,T=120,q=0.25): 0.35478 vs 0.44648 → **−20.5%**
  - **改善随 q 单调上升** —— 这是结构性结论，不是样本期巧合
- 硬/软阈值在低 q 下 ≈ sample；LW 反而最差（0.52377，均匀收缩引入系统性偏差 +3.1%）

稳健性：
- 阈值扫描**平坦**（0.85×–1.15× 净夏普 0.398–0.405，跨度 <0.007）= 无幸运参数
- **σ 估计方法很关键**：`max_eigen` 灾难性失败（rmt_hard 夏普 0.400→0.243，换手 5.3%→13.8%）；`rmt_rie` 对 σ 方法完全不敏感（四种方法都是 0.3949）
- 成分数回归 R² 全在 0.0005–0.040 → 推翻「条件数高则预测差」的朴素假设

**本轮修复的两个真实 bug**
1. **`drawdown_series` 漏掉首期回撤**（重要！）：原实现 `wealth=cumprod(1+r)` 从 1+r₀ 开始，**初始财富 1.0 从未进入滚动峰值**，首期为负时该期回撤被静默丢弃。10 期连续 −10% 报 0.6126 而非正确的 0.6513。修复：前置 1.0 再对齐输出。已加重回归测试。
   - 注：主回测用的是月度序列且首月为正，所以论文数字未变，但这是潜在缺陷。
2. **`run_robustness.py` 的 pivot key 映射错误**：`sigma` sweep 的列名是 `sigma_method` 不是 `sigma`，导致 `--sweep all` 在最后一个 sweep 崩溃（KeyError: 'sigma'）。修复：新增 `SWEEP_KEY` 显式映射表。

- 写测试时**纠正了我自己的多个错误先验**（重要，避免以后重犯）：
  - `eigenvalues_before/after` 是**升序**（来自 `eigen_decompose.eigenvalues`），不是降序

  - `max_weight` 参数被 `inverse_variance` / `hrp` **忽略**（闭式解，无该参数）
  - `risk_parity` 与 `max_diversification` 在**等相关协方差上精确重合**（数学恒等，不是 bug）
  - 对角协方差上 min-var = inv-var = HRP = 逆方差；risk_parity 给 dyadic 1,1/2,1/4
